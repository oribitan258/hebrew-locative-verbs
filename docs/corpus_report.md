## 2. How the inventory works

1. **Enumerate.** Every file under `corpora/` is listed, using the same walker as the checksum baseline.
2. **Profile (read-only, 12 processes in parallel, ~70 s).** Each file's bytes are read **once**. From them we compute:
   - the SHA-256;
   - the encoding (detected strictly);
   - counts of lines, non-empty lines, tokens, Hebrew tokens, Hebrew letters, niqqud, cantillation, Latin letters and digits;
   - anomaly counters (BOMs, control characters, odd line separators, mojibake indicators);
   - markup-artifact counters (`prefix=`, `token=`, `[ IMG ]`, URLs).
3. **Metadata.** Each corpus has a parser for its path and file-name conventions. It records fields such as book, tractate, commentary and base work, sefer/hilchot/chapter, author/title/year/genre, and source/date. A name that does not fit the expected pattern is flagged (`meta_issue`), never guessed. **All 404,294 names parsed cleanly.**
4. **Curation tags** from [`config/curation.yaml`](../config/curation.yaml):
   - every file gets a `stratum` and a `period_status` (`in_period` / `out_of_period` / `needs_review`);
   - the first matching rule wins;
   - a catch-all rule exists for each corpus, and the tests require that no file reaches it.
5. **Exact duplicates.** Non-empty files with identical bytes are grouped. The file with the alphabetically first path is canonical (`dup_rank = 0`); the others are marked `is_dup_copy`, with `dup_of` pointing to the canonical file.
6. **Default comparison set** (`include_default`): the file is text, not blank, `in_period`, and not a duplicate copy. Every excluded file lists its `exclusion_reasons`. **Nothing is deleted.** Excluded files remain in the catalog with full measurements and will still be parsed (decision D-003).
7. **Verification gate.** Before writing, the catalog is checked against:
   - the live filesystem (paths and sizes);
   - the baseline (path, size and SHA-256, row by row);
   - the git-tracked anchor (the catalog's own content digest must equal the anchor's).

   If any check fails, nothing is written. The result is recorded in `documents.manifest.json`.

**Definitions** used here and in all later milestones:
- *Line*: delimited by `\n` only (a trailing `\r` is part of CRLF).
- *Token*: a whitespace-separated run of characters.
- *Hebrew token*: a token containing at least one letter U+05D0–U+05EA.

These are raw orthographic counts for inventory purposes. They are **not** the linguistic word counts that M6 will compute from Dicta's output.

## 3. Findings per corpus

### Mikra (39 files, 23,206 verses, 267,866 Hebrew tokens)
- One verse per line, in UTF-8 with CRLF endings. Fully vocalized (0.86–0.88 niqqud marks per letter) with cantillation (~0.20 per letter).
- 39 books: Torah 5, Prophets 21, Writings 13. All are in the default set.
- As already known: no chapter:verse labels, Ketiv/Qere notation, and maqaf written as `-`. These are handled in M2; Ketiv/Qere stays a hypothesis (D-009).
- **Note:** Daniel and Ezra contain Aramaic passages, and Jeremiah 10:11 and Genesis 31:47 contain Aramaic words. M2 should flag these verses at unit level, so that statistics can exclude them.

### Modern (402,603 files, 134,095,012 Hebrew tokens; default set 132,320,112 = 98.7%)
- **Encoding:** Windows-1255 throughout, apart from 159 pure-ASCII files (100 of them the logs listed below, 59 short English or numeric texts) and 7 empty Haaretz files. The `medical/questions/text_utf` folder is also cp1255, despite its name. Decoding produced zero errors.
- **Haaretz is 74.1% of Modern** (99.4M tokens, 279,360 text files). Next come a7 (9.3%) and the Knesset (8.6% across Knessets 16 and 17). Literature is 2 files: original and translated, ~0.57–0.59M tokens each. TheMarker spans 2002-05-12 to 2002-10-24.
- **Auxiliary, non-text files:**
  - 99 `*.log` files and **one 7-Zip log disguised as `haaretz/6/60.7z.txt`**, detected by its content;
  - all 100 are `file_kind = auxiliary` and excluded.
- **Exact duplicates:** 4,295 groups with 6,265 copies, holding 1,774,900 Hebrew tokens and excluded from the default set.
  - Haaretz has 5,146 copies, mostly near-empty pages: the median copy has 6 Hebrew tokens, e.g. a page reading only "עדכון אחרון - … תמונת מדור".
  - Blogs have 665 copies, which are real re-posted entries (median 313 tokens).
- **Tokenization artifacts** (counts in `results/inventory/artifacts.csv`):
  - **`prefix=X` appears 1,159,212 times in 212,506 files** (Haaretz, ynet, nrg) and 141 times in Rambam.
    - It encodes a Hebrew prefix attached to a non-word token: `ברח'` → `prefix=ב token=רח'`, `כ-20` → `prefix=כ - 20`.
    - Fed to Dicta as-is, it would corrupt both tokens and parses, so **M2 must reconstruct the original form**.
  - `token=`: 8,922. `[ IMG ]`: 115 (a7). URLs: ~22k, mostly Haaretz and Tapuz.
  - Each Haaretz file starts with a header ("עדכון אחרון - HH:MM DD/MM/YY") and uses double spaces.
- **Near-empty "stub" pages** with ≤15 Hebrew tokens: 8,695 in Haaretz, 1,960 in a7, 510 in blogs. They stay in the catalog; they add few tokens but many tiny documents.
- **66 non-blank Modern text files contain no Hebrew** (e.g. English-only blog posts and English Haaretz pages). 205 files are mostly non-Hebrew (Hebrew letters < 50% of all letters).

## 4. Where the catalog is and how to use it

| Artifact | Purpose |
|---|---|
| `data/catalog/documents.parquet` | One row per file, 62 columns (identity, encoding and quality, size counts, artifacts, duplicates, metadata, curation, provenance). Documented in `src/hebloc/catalog.py` and [`data_dictionary.md`](data_dictionary.md) |
| `data/catalog/documents.manifest.json` | Creation time, code commit, curation hash, per-corpus counts, verification results |
| `results/inventory/*.csv`, `docs/corpus_inventory_tables.md` | Generated summary tables |

```python
from hebloc.catalog import documents
docs = documents("hazal", default_only=True)          # pandas DataFrame
docs = documents(text_only=True, columns=["doc_id", "rel_path", "encoding", "stratum"])
```

`doc_id` is a stable 12-hex hash of the path relative to `corpora/`. M2 will key every sentence unit to it.
